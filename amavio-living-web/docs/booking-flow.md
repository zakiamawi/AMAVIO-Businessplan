# Booking Flow

## V1

1. Nutzer wählt Zielgruppe oder Wohnform.
2. Nutzer stellt Anfrage.
3. API validiert Daten serverseitig.
4. Anfrage wird als `prepared` bestätigt.

## P1

Persistenz in Datenbank, Verfügbarkeitsprüfung, Terminbuchung, Dokumentenupload, Statusverfolgung und E-Mail-Benachrichtigung.
