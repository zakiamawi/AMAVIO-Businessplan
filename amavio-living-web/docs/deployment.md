# Deployment

## V1

- Lokale Ausführung mit `npm run dev`
- Produktionsbuild mit `npm run build`
- Zielplattform: Vercel empfohlen

## Vor Produktion

- echte Domain in `metadataBase`, `sitemap` und `robots`
- Environment Variables setzen
- Error Monitoring aktivieren
- Datenschutz- und Impressumsdaten final prüfen
- Preview Deployment visuell abnehmen
