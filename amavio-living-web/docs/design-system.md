# Design System

## Tokens

- Farben: Petrol, tiefes Grün, Creme, Terrakotta, Bronze, Champagner, Sage
- Typografie: Display für große Markenmomente, Sans für UI und Fließtext
- Radien: 8px für funktionale Karten, größere organische Radien nur für Bildmasken
- Schatten: weich und großflächig, keine harten Standard-Dropshadows
- Breakpoints: mobile-first, ab 640px und 960px verdichten

## Komponenten

Header, Button, Zielgruppenkarte, Service Card, Anfrageformular, Wohnkonzeptkarte, Prozessschiene, FAQ, Statusbadge, Plattformmodul.
