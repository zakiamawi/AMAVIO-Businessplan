# Product Roadmap

## P0

- Öffentliche Website
- Wohnkonzepte und Anfrage
- Arbeitgeber-, Bewohner- und Immobilienpartnerpfade
- Kontaktformular mit Servervalidierung
- rechtliche Platzhalter ohne erfundene Daten

## P1

- Login
- Bewohnerportal
- Arbeitgeberportal
- Admin-Ansicht
- Dokumentenupload
- Warteliste
- E-Mail-Automationen
- CRM-Integration

## P2

- Zahlungen
- Rechnungen
- digitale Verträge
- Matching Engine
- Community-Funktionen
- Mobile App
- Partnerportal
- Operations-Dashboard
