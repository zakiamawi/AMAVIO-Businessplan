# Media Review

## Aktueller Stand

Alle eingebundenen Medien in `public/images` sind SVG-Konzeptdarstellungen und damit `placeholder-only`.

## Produktionsfreigabe

Higgsfield- oder Realbild-Assets dürfen erst produktiv eingesetzt werden, wenn sie auf Markenkonsistenz, Fotorealismus, Anatomie, kommerzielle Nutzbarkeit, Dateigröße, mobile Crops und Textflächen geprüft wurden.
